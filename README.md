# Universal Package Manager for KDE Plasma

Это проект по созданию унифицированного графического менеджера пакетов для дистрибутивов на базе Arch Linux (Cachy OS). Его цель — предоставить единый интерфейс для управления приложениями и пакеты, независимо от того, установлен ли они через `pacman`, Flatpak или AUR.

## ⚙️ Архитектура
Проект будет разделен на следующие компоненты:
1.  **Core Logic (`src/pkg_manager.py`):** Бэкенд, отвечающий за взаимодействие с системными менеджерами пакетов и нормализацию данных.
2.  **GUI Interface (PySide6):** Фронтенд для KDE Plasma на Python, который будет отображать данные из ядра.

## 🚀 План разработки
1. **[DONE] Core Logic:** Реализация функций для получения списка пакетов из Pacman и Flatpak.
2. **[NEXT] GUI Implementation:** Создание графического интерфейса PySide6.
3. **[FUTURE] AUR Integration:** Интеграция сложной логики работы с Arch User Repository (AUR).

## 💡 Замечания по использованию
В процессе разработки, основная логика будет находиться в папке `src/`.
